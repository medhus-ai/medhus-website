# Conventions

Seed this file during Phase 0.5.

## Engineering

- Keep changes small and reviewable.
- Prefer existing project patterns.
- Add tests for new behavior.
- Declare known gaps in the PR Test Envelope.

## Automation

- At most one active state label per issue.
- Retry labels are metadata only.
- Doppler is the machine-secret source.
- Agents do not merge to main.
